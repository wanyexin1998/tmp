## 下载视频（电脑浏览器）

1. **[点击下载视频下载器 ZIP](https://github.com/wanyexin1998/tmp/raw/refs/heads/main/VIDEO_DOWNLOADER.zip)**。
2. 解压，双击其中的 **OPEN_TO_DOWNLOAD.html**，用 Chrome、Edge 或 Safari 打开。
3. 页面会自动从此仓库取回并校验原片。完成后，点击 **保存 MP4 视频**；也可直接在页面播放。

无需安装 Python，不需要手动合并分段。原始视频约 63.8 MB；加载时请保持能访问 GitHub。
